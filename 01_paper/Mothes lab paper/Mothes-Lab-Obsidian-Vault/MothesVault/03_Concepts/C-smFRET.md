# 단분자 FRET (smFRET)

하나의 분자에 **공여체/수용체 형광 염료 쌍**을 붙여, 두 지점 사이 거리 변화를 시간에 따라 실시간 추적하는 기법.

**왜 강력한가**
- 앙상블 평균에 가려지는 **소수 상태(minor population)와 전이(transition)**를 본다
- 구조생물학이 주는 스냅샷에 **시간축**을 붙인다

**실무적 난관 (이 랩이 푼 문제)**
1. 삼량체 하나에 염료를 **정확히 2개만** 붙이기 → 비천연 아미노산/펩타이드 태그
2. 표지 후에도 **감염성이 유지**되는지 반드시 검증
3. 광표백 전 충분한 관측 시간 확보 (산소 제거계)
4. HMM 기반 상태 분류 — 상태 개수를 몇 개로 볼지는 **모델 선택 문제**

**한계:** 관측 창(ms~s) 밖의 동역학은 보이지 않는다. 절대 거리가 아닌 상대 FRET 효율.
