# 🔌 기존 볼트(`keonwoong - 개인`)와 연결하기

## 0. 설계 원칙
이 모듈은 **기존 볼트를 건드리지 않습니다.**
- 폴더는 최상위 `Mothes-Lab/` **하나만** 추가 → 기존 `00_`, `01_` 같은 폴더명과 충돌 없음
- 모든 노트에 `#mothes` 태그 → 검색·그래프·Dataview에서 **한 덩어리로 분리 가능**
- 모든 Dataview 쿼리가 **폴더가 아니라 태그 기준** → 폴더를 옮겨도 안 깨짐
- 파일명이 전부 고유 접두사(`P20xx-`, `C-`, `T1~T5`) → 기존 노트와 이름 충돌 없음

## 1. 설치 (2분)
1. zip 압축 해제
2. `Mothes-Lab` 폴더를 **통째로** `keonwoong - 개인` 볼트 루트에 끌어다 놓기
3. Obsidian 재시작 → `Mothes-Lab/_Mothes-Lab-대시보드.md` 열기
4. 이 노트를 **⭐ 즐겨찾기(Star)** 또는 좌측 사이드바에 고정

> ⚠️ 볼트를 새로 만들지 마세요. 별도 볼트로 열면 기존 노트와 링크가 끊깁니다.

## 2. 필수 플러그인 (Settings → Community plugins)
| 플러그인 | 이 모듈에서의 용도 | 설정에서 반드시 할 것 |
|---|---|---|
| **Dataview** | 대시보드 자동 테이블 | `Enable JavaScript Queries`는 꺼도 됨 |
| **Spaced Repetition** | 논문 노트의 `질문::답` 카드 | Flashcard tags에 **`flashcard`** 추가 |
| **Templater** | 새 논문 노트 생성 | Template folder: `Mothes-Lab/05_Templates` |
| **Excalidraw** | 백지 재구성 그림 | Excalidraw 폴더를 `Mothes-Lab/07_Drawings`로 지정 |
| (선택) **Kanban** | 12주 진행판 | — |

## 3. 기존 볼트와의 연결 고리 만들기
### (a) 홈 노트에 한 줄 추가
기존 볼트의 메인 노트(예: `홈.md`, `Index.md`)에 붙여넣기:
```markdown
- 🧬 [[_Mothes-Lab-대시보드|Mothes Lab 스터디]]
```

### (b) 데일리 노트 연동
데일리 노트 템플릿 하단에 [[_데일리노트-스니펫]] 내용을 붙여넣으면, 매일 그날의 논문·카드·질문이 자동으로 뜹니다.

### (c) 내 프로젝트 노트와 연결
기존 볼트에 이미 CD169·VLP·IVIS 프로젝트 노트가 있다면, 그 노트 안에 다음 링크를 넣으세요:
```markdown
관련 문헌: [[내-연구와의-접점]]
```
반대 방향 링크는 [[내-연구와의-접점]]에 이미 걸려 있습니다. 기존 노트의 **정확한 파일명**을 알려주시면 제가 양방향으로 다 이어드립니다.

## 4. 그래프 뷰에서 분리해서 보기
Graph view → Filters에 검색식 입력:
- 이 모듈만 보기: `tag:#mothes`
- 내 연구와의 접점만 보기: `tag:#mywork OR tag:#mothes`
- 기존 볼트에서 제외하고 보기: `-tag:#mothes`

Groups(색상)도 추천:
| 검색식 | 색 |
|---|---|
| `tag:#paper` | 파랑 |
| `tag:#concept` | 초록 |
| `tag:#theme` | 주황 |
| `tag:#mywork` | 빨강 ← 내 연구 |

## 5. EndNote 브리지 (Zotero 대신)
EndNote를 쓰시므로 Zotero 플러그인 대신 **PMID 기반 링크**로 연결합니다.
- 각 논문 노트 frontmatter에 `pmid:` 가 있고, 본문에 PubMed 직링크가 있습니다
- EndNote 라이브러리에서 해당 PMID로 검색하면 1:1 대응
- PDF를 볼트에 넣고 싶다면 `Mothes-Lab/08_PDFs/`를 만들고 파일명을 `PMID_25298114.pdf` 형식으로 통일 → 노트에 `[[PMID_25298114.pdf]]`로 임베드
- 원고 작성 시 인용은 **EndNote에서** 하고, Obsidian은 읽기·사고 전용으로 유지 (역할 분리가 핵심)

## 6. 동기화 주의
- iCloud/Dropbox 동기화 볼트라면 `.obsidian` 폴더 충돌에 주의
- Obsidian Sync 사용 시 `Mothes-Lab` 폴더가 동기화 대상에 포함됐는지 확인

## 7. 유지보수
- 새 논문 추가: `Ctrl+P` → Templater → `템플릿-논문노트`
- 주간 회고: `템플릿-주간회고`
- 논문을 다 읽으면 frontmatter의 `status: 읽기전` → `status: 완독` 으로만 바꾸면 대시보드가 자동 갱신됩니다
